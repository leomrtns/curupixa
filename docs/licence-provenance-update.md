# Provenance review after the numerical and RNG replacements
Historical review: the [MIT transition record](mit-transition.md) supersedes statements below about the current project licence and unresolved items.
The current library still carries Curupixa's GPL-3.0-or-later notice. This review concerns incorporated third-party code that would matter for a later permissive release. Leo has confirmed control over his own contributions and code brought from his own repositories; the presence of an earlier GPL notice on that work alone does not require replacing it.
The R/GSL numerical replacements and the identified portable-lib/Mailund/Xorgens paths are documented in [probability numerics](probability-numerics.md) and [random generators and hashes](random-hashing.md). The new assignment adapter uses SciPy's BSD source, and the split-rotation hash uses MIT ntHash code. Their notices are shipped and installed. The new graph, medoid and density-hierarchy kernels were written from algorithm descriptions, with paper references in source and documentation.
The current `rolling_hash.c` is a polynomial byte-window implementation; it contains no retained MMseqs2 code. Historical references to GOPTICS, Rec-I-DCM3, SVDLIBC and the older Hungarian implementation likewise do not establish that those bodies remain in the current implementations. The active OPTICS, hashtable, dense SVD and existing assignment sources use the later Curupixa implementations. This review found no further clearly identified third-party GPL function body in those active modules; it was not an exhaustive source-similarity audit against every historical upstream revision.
The tracked but unbuilt `lib/global/__unused.c` was removed. It contained a pilot entropy/seeding function, two old Brent/STD61-style generators and a duplicate FastHash mixer. None was declared in public headers or called elsewhere. The provenance of those historical snippets was not established, so they were not presented as permissively cleared code.
