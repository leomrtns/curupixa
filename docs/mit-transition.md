# MIT transition and incorporated code
Curupixa's own code is now offered under MIT. Leonardo de Oliveira Martins confirmed control of the rights needed for this change, including employer contributions and his own code imported from biomcmc-lib, guenomu, genefam-dist and branchtraits. Earlier GPL releases retain their original permissions. The transition does not erase historical attributions or relicense third-party components exclusively as MIT.
## Review scope and findings
The review builds on the [numerical replacement record](probability-numerics.md), [RNG/hash replacement record](random-hashing.md), and the historical [7 November audit](261107.mit-licence-audit.md). Active library sources, public/internal headers, tests, examples, build definitions and distributed notices were inspected for retained third-party implementations and conflicting licence declarations. Current tree, likelihood, reconciliation and inference calculations were distinguished from their historical reference implementations. phyloSMC's particle management, proposals, process backend and documentation were reviewed separately.
No remaining third-party GPL implementation was identified in the tracked runtime sources within this review. The identified R/GSL/qrng and GPL-intermediary RNG/hash implementations had already been replaced or removed. This review additionally removes the unresolved blog-derived integer mixers and their generator variants. No claim of exhaustive source-similarity comparison or independent legal clearance is made.
The owner-controlled notices were changed to MIT only after those removals and the grant checks below. Files incorporating third-party implementations retain their attribution and applicable licence terms. Mixed source files use compound SPDX expressions where appropriate. Scientific citations describe mathematical provenance separately from permission to incorporate particular source code.

## Removed variants
RRMixer, NASAM, Moremur and the distinct historical Stafford `entropy` mixer had blog descriptions without an established original permission record. Their active implementations and declarations were removed. Context generator IDs 2 and 13 are now rejected rather than reassigned, joining previously retired ID 19. The default xoshiro256++ streams and retained generator outputs are unchanged. The [integer-mixer guide](integer-mixers.md) preserves algorithm-class pseudocode, mathematical descriptions and original links for possible reinstatement after permission is established.
## Build tools and other material
The four tracked Autoconf Archive macros and the FSF `INSTALL` file retain their own permissive copying notices. Generated Autotools support files in a source distribution retain their original licences and distribution exceptions; these tool files are separate from the compiled library. A source distribution can therefore contain GPL-labelled build helpers with exceptions while the runtime code is offered under MIT and the recorded permissive component terms.
Optional compression libraries retain their own terms; they are not relicensed by Curupixa. The owl image has the separately documented public-domain provenance in the README. Documentation containing historical GPL names remains historical evidence, rather than an assertion that those implementations are active dependencies.
`LICENSES/` is included in source distributions and installed notices. Retain those notices when redistributing relevant binary or source components. The top-level MIT licence applies to the project's own contributions, with incorporated third-party terms preserved.
