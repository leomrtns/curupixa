# Comparison and inference interfaces
The [library organisation](library-architecture.md) describes linking and dependencies. This guide distinguishes the calculations implemented in this branch from the searches and probability models using them. All new APIs use explicit inputs and return recoverable statuses. Public result arrays are owned or borrowed as specified in their headers; no analysis buffers are attached to ordinary trees.
## Ordinary quartet comparisons
`crpx_quartet_index_new()` prepares topological pairwise distances between selected, distinct tips. The arrays for two trees must list corresponding tips in the same order. Extra unselected tips are permitted; labels and branch lengths are ignored. `crpx_quartet_topology()` returns the induced topology of one quartet, including unresolved topology. `crpx_quartet_compare()` returns resolved agreement, resolved conflict, one-sided resolution and jointly unresolved counts. `crpx_quartet_disagreements()` counts unequal topologies, treating two unresolved quartets as agreement. The separate counts permit another weighting or normalisation without repeating enumeration.
Preparation uses an ancestry index and costs $O(V\log V+N^2\log V)$ time and $O(N^2)$ retained storage for $V$ nodes and $N$ selected tips. Repeated comparison allocates no memory and enumerates all $\binom{N}{4}$ quartets. This is an exact reference implementation for modest taxon counts, not the subquartic counting machinery of large-scale quartet-distance packages.
## Paralogy-aware quartet objective
`crpx_paralog_quartets_new()` accepts a rooted binary gene tree, an explicit gene-copy-to-species map and caller-supplied duplication/speciation tags. Speciation tags must separate disjoint species sets. Eligible quartets contain four distinct species and have speciation at every triple LCA. Records with the same species quartet and anchor LCA form one equivalence class. `crpx_paralog_quartets_score()` counts how many prepared classes agree with a candidate species-tree quartet index. Duplicated copies within one class contribute once; independently duplicated loci may contribute different classes. Absent species contribute no quartets.
This implements the per-locus objective in Definitions 1–5 of [Zhang et al. (2020)](https://doi.org/10.1093/molbev/msaa139), independently of rooting, tagging and species-tree search. Preparation explicitly enumerates gene-copy quartets and sorts eligible records. Candidate scoring is allocation-free and linear in the number of retained classes. This branch does not implement ASTRAL-Pro's constrained bipartition dynamic programme, search-space construction or automatic rooting/tagging. The generic NNI optimiser below can use this objective, but is a different search procedure.
## Tanglegrams with unequal sizes
`crpx_tanglegram_workspace_new()` snapshots two rooted ordered trees and an array of explicit tip links. The trees may have different numbers of tips. Unlinked tips, multiple links sharing a tip and multifurcations are supported. Duplicate links retain their multiplicity. Links sharing either endpoint do not cross. These rules permit several gene copies to link to one species without expanding the species tree merely to draw or score those links.
`crpx_gene_species_tanglegram_new()` in the gene/species library prepares one link per gene copy from the explicit species map and calls the same general constructor. Species without gene copies remain unlinked.
`crpx_tanglegram_optimise()` changes child orders on both sides while preserving the supplied rooted subtrees. It first tries improving swaps, then enumerates child permutations while the caller's evaluation budget remains. A Fenwick counter counts crossings in $O(V+E\log L)$ per evaluation, where $V$ is the combined node count, $E$ the number of links and $L$ the second tree's leaf count. Repeated optimisation reuses all storage; input trees are neither retained nor changed.
The search space is the product of child-degree factorials, so exhaustive minimisation is expensive. Set `max_evaluations=0` to request exhaustive search. A positive limit returns the best orders found within that budget. `result.exact` is true only after exhaustive completion or attainment of zero crossings. Otherwise the returned count is an upper bound on the minimum. The result arrays contain every tip, including unlinked ones, and remain valid until the next call or workspace destruction. The supplied storage roots determine the permitted embeddings; root selection is a separate problem.
## LCA reconciliation and selected-root mappings
`crpx_reconcile_lca()` returns the mapping and event counts for a fixed rooted gene tree. `crpx_reconcile_all_roots_into()` scores all edge rootings using two directional passes and reusable worker arrays. `crpx_reconcile_all_roots()` uses the same implementation as a one-off wrapper with an independently owned result. `crpx_reconciliation_root_mapping()` extracts mappings for a chosen scored edge without altering the original tree. The original artificial-root ID identifies the selected virtual root in that output.
The species tree is rooted and binary; these operations allow several gene copies per species. Losses can be counted against the full or represented species tree. Duplication, loss and extra-lineage minima remain independent: their best roots can differ. The legacy extra-lineage identity is applied to each candidate separately, using represented-species losses. These score conventions do not infer how many biological ILS events actually occurred.
## Dated and undated DTL calculations
`crpx_dtl_species_new()` prepares a rooted binary host/species tree. NULL ages select undated branches. An explicit age for every node selects dated segments; leaves are contemporary at age zero, parents must be strictly older and an origin age defines the top of the root stem. Dated branches are sliced at every species divergence time. Transfers occur only between segments in the same open interval. Gene events within an interval can be ordered consistently with the gene tree. Undated transfers join incomparable branches without imposing global temporal consistency.
`crpx_dtl_evaluate()` accepts a rooted binary gene tree, explicit leaf correspondence and nonnegative finite duplication, transfer and loss costs. Several gene copies may map to the same species. Names and branch lengths play no role. Ordinary phylogenetic callers can use the same kernel with any explicitly supplied correspondence; a biological label does not change its implementation.
The origin is fixed at the top of the species root stem. Species descent either divides the two gene children at a speciation or retains one lineage and pays for the other lineage's loss. Duplication and transfer consume a branching in the observed gene tree. `CRPX_DTL_MINIMUM_COST` minimises total event cost; `crpx_dtl_traceback()` returns one selected history's events, branch mappings and event counts. Traceback is allocation-free after evaluation. Mutable DP and traversal capacity is retained, while structural validation still allocates temporary arrays.
The implemented model enumerates finite observed-tree histories. It excludes hidden extinct duplication subtrees and transfer-loss chains. `CRPX_DTL_LOG_PARTITION` uses the same recurrence to return
$$
\log Z=\log\sum_{h\in\mathcal H(G,S)}\exp[-C(h)].
$$
Costs are event penalties, not continuous-time birth/death rates. Dated histories distinguish event segments rather than integrating continuous event times; the partition depends on the slicing convention. This is not the continuous-time ALE/GeneRax reconciliation likelihood. A full extinction-aware birth–death model and integration of ALE clade uncertainty with DTL remain unimplemented.
In the inference library, `crpx_dtl_minimum_log_probability()` returns the minimum cost, log partition and conditional log probability of one selected minimum-cost history:
$$
\log P(h_*\mid G,S,C)=-C(h_*)-\log Z.
$$
This is normalised over reconciliations of the supplied trees, not over possible gene-tree topologies. Equal-cost histories retain separate probabilities. The function evaluates the shared recurrence in both modes, retaining capacity, and finishes with minimum-cost traceback available. The same mutable workspace must not be shared across simultaneous evaluations.
## Empirical amalgamation
`crpx_amalgamation_new()` constructs an empirical conditional-clade distribution from weighted rooted binary sample trees. Every sample contains the same uniquely identified gene copies; explicit tip arrays provide correspondence, independently of labels or species membership. It records counts for each observed clade and each of its binary splits. Split probabilities are split counts divided by parent-clade counts. Immutable models can be shared among workers.
`crpx_amalgamation_log_probability()` multiplies those conditional split probabilities in log space. An absent clade or split has probability zero. `crpx_amalgamation_sample()` samples the same conditional splits to assemble a new tree, potentially combining splits in a way absent from the original sample. A caller-owned uniform callback supplies randomness. Generated tips receive caller-supplied unique labels; branch lengths are absent. A gene-copy-to-species map remains separate, so paralogs need no special change to this distribution.
The empirical conditional-clade construction follows the amalgamation principle described by [Szöllősi et al. (2013)](https://doi.org/10.1093/sysbio/syt054). It does not reproduce every part of the ALE software. Clade lookup currently uses a simple linear table; preparing and evaluating large posterior samples should be benchmarked before replacing that table with a hashed representation. Evaluator workspaces retain mask capacity, but validation/traversal still perform preparation; each sample allocates its output tree and construction scratch.
## Independent optimisation and acceptance
`crpx_tree_search_nni()` minimises a finite caller-supplied objective by steepest descent through rooted binary NNI neighbours. It clones the starting tree once; stable tip IDs preserve explicit maps. The callback can evaluate ordinary likelihood, reconciliation costs, a sum of per-locus quartet scores or another objective, using its own parameters and reusable state. The callback must be deterministic for fixed parameters and refresh any topology-dependent snapshots. The final callback evaluates the returned topology so numerical caches describe that result.
`crpx_tree_search_unrooted_nni()` adds the exchanges across the unrooted edge represented by the artificial root's two child edges. This matters for quartet and unrooted RF objectives: rooted moves adjacent to that root otherwise only relocate it. The same implementation performs both searches. The unrooted entry point still accepts a binary storage tree with a degree-two root.
The search stops at a strict local optimum or a caller-selected move limit. Its result distinguishes those outcomes. Branch lengths remain attached to node IDs during swaps; their optimisation is the caller's responsibility. NNI search does not guarantee a global optimum and does not implement the ASTRAL dynamic programme. `crpx_metropolis_accept()` separately evaluates the acceptance decision from supplied log-target change, proposal ratio and log-uniform variate; it owns neither a chain nor an RNG.
## Validation
The new tests cover ordinary quartet resolutions, paralog equivalence classes, conditional-clade normalisation and sampling of previously unseen trees, and analytic DTL partitions. Dated/undated tests include a transfer-timing example with different optima and verify traceback event costs. Every selected-root LCA mapping is checked against independent reconstruction and fixed-root reconciliation. Tanglegram tests compare all link subsets between two- and three-tip stars against independent enumeration, and cover unequal sizes, repeated endpoints and multifurcations. Separate tests exercise callback NNI search and original-tree preservation.
